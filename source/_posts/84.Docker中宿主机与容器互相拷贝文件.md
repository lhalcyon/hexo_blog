{% note info %}

docker cp 容器名:容器内文件全路径 宿主机对应目录路径

docker cp 宿主机:宿主机文件全路径 容器内目录路径

{% endnote %}

```
docker cp f5aab201ecfd:/home/mediapipe_holistic_tracking.aar ../mp_build/
docker cp ../build/abc.jar /home/build
```
