{% note info %}

很多实用的 Docker 命令经常不记得 , 记录于此

{% endnote %}

列出所有容器ID

```bash
docker ps -aq
```

停止所有容器

```bash
docker stop $(docker ps -aq)
```

删除所有容器

```bash
docker rm $(docker ps -aq)
```

删除所有不使用的镜像

```bash
docker image prune --force --all
```

删除所有停止的容器

```bash
docker container prune -f
```

清理资源命令

```bash
docker system prune
```

删除 `exited` 状态容器

```bash
docker rm $(docker ps --all -q -f status=exited)
```
