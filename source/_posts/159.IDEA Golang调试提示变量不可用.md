记录IDEA调试Golang程序变量不显示问题

{% endnote %}

golang 版本升级后 , 进行 debug 调试 , 面板显示变量不可用 , 而且运行后有警告日志 `WARNING: undefined behavior - version of Delve is too old for Go version go1.25.5 (maximum supported version 1.24)`

### 解决办法

#### 1. 更新 `dlv` 版本

```
go get -u github.com/go-delve/delve/cmd/dlv@latest 
go install github.com/go-delve/delve/cmd/dlv@latest
```

查看 `delve` 版本

```
$ dlv version
```

重启 IDEA

#### 2. 设置 IDEA dlv 版本

`Help` -> `Edit Customer Properties` -> 添加 `dlv.path=${GOPATH}/bin/dlv.exe`  这里GOPATH是本机的环境变量，相应替换

然后重启 IDEA，解决

> 话说工具环境错误还是传统搜索快一点, AI会胡诌搜索一些.
