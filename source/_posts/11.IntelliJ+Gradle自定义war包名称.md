最近在帮朋友开发小程序的 Java 后端,项目采用 Gradle 构建,使用IntelliJ开发. 开发中经常需要发包到外网上,方便前端联调,而IntelliJ默认构建的 war 包名称为`项目名-版本号`,使得每次上传war包至服务器tomcat时还得手动重命名,发布次数多了,就显得很繁琐.这里就水一篇,简短说明下 **IntelliJ中Gradle构建如何自定义war包名称**.

首先打开 Project Settings

![](https://halcyon-1258836598.cos.ap-guangzhou.myqcloud.com/blog/006tNc79gy1fopikcl9olj30mc01o3ys.jpg)

选择 Artifacts

![](https://halcyon-1258836598.cos.ap-guangzhou.myqcloud.com/blog/006tNc79gy1fopiml70qkj31kw190qa2.jpg)

前两个 `Gradle:xxx`  是创建Gradle项目并添加tomcat后,自动生成的.我们这里点击 + 新增

![](https://halcyon-1258836598.cos.ap-guangzhou.myqcloud.com/blog/006tNc79gy1fopiqgxj6ej31bg0hy0z2.jpg)

选择 `Web Application: Archive`	->	`Empty`

![](https://halcyon-1258836598.cos.ap-guangzhou.myqcloud.com/blog/006tNc79gy1fopj7lkx3cj31bu0e0tbt.jpg)

修改war包名称及输出路径

![](https://halcyon-1258836598.cos.ap-guangzhou.myqcloud.com/blog/006tNc79gy1fopjt8ggu0j31c00midjh.jpg)

添加war包内容,同样选择 Artifact

![](https://halcyon-1258836598.cos.ap-guangzhou.myqcloud.com/blog/006tNc79gy1fopk3yib95j30qg0qoabp.jpg)

选择 Gradle: xxx (exploded) 

![](https://halcyon-1258836598.cos.ap-guangzhou.myqcloud.com/blog/006tNc79gy1fopk8hw84uj30h40aygmy.jpg)

之后打包只能选择 Build -> Build Artifacts 然后选择自定义的build, 然后在输出目录下即可找到war包
