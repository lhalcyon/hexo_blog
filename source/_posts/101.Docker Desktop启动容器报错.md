{% note info %}

 安装 Docker Desktop 后启动容器报错 `error getting credentials - err: exec: "docker-credential-desktop": executable file not found in $PATH` 

{% endnote %}

在 用户下的 `/.docker/config.json`，把 `credsStore` 改成 `credStore` 就可以了
